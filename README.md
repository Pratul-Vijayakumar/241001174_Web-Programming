# EcoMart – Sustainable Product Marketplace (Web Programming Project)

A complete, responsive, zero-waste and plastic-free e-commerce web application built with **HTML5**, **CSS3**, **Vanilla JavaScript**, and **PHP 8**.

> **Tagline:** *"Shop Green. Live Better."*

---

## 📁 Repository Contents

- **`ecomart/`** – Full source code for the EcoMart web application.
  - Interactive product catalog & detail pages
  - LocalStorage shopping cart & session-based demo checkout
  - User authentication (Login / Register / Session management)
  - Responsive green-aesthetic UI with zero heavy CSS/JS frameworks
- **`EcoMart_Sustainable_Product_Marketplace_Presentation.pptx`** – Project presentation slide deck covering system design, architectural constraints, features, and screenshots.

---

## 🚀 How to Run Locally

1. Ensure **PHP 8.0+** is installed on your computer.
2. Open terminal in the `ecomart` folder:
   ```powershell
   cd ecomart
   ```
3. Start the PHP built-in server:
   ```powershell
   .\start-server.bat
   # or
   php -S localhost:8000
   ```
4. Open your browser and navigate to:
   ```
   http://localhost:8000
   ```

For detailed documentation, design specs, and page breakdowns, see [ecomart/README.md](ecomart/README.md).
